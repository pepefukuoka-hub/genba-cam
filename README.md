# 現場の目

スマホ2台を、同じWi-Fi(またはテザリング)でつなぎ、片方のカメラの映像を、もう片方で見るウェブアプリです。インストールは不要です。

- 映像は、スマホ同士で直接送ります(WebRTC)。外のサーバーは使いません。
- 最初の接続は、QRコードの交換で行います。映す側のQR → 見る側の標準カメラで読み取り → 見る側のQR → 映す側のカメラで読み取り。
- 形式は VP8 です。ChromeとSafariの両方で使えます。
- `vendor/qrcode.min.js`: qrcode-generator 1.4.4(MIT)、`vendor/jsQR.js`: jsQR 1.4.0(Apache-2.0)
